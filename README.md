# 偉人とともだち！顔パズル

スマホのブラウザで遊べる、無料の60秒パズルです。ログイン・インストール不要。広告・課金はありません。

**遊ぶ：** https://actpraise-droid.github.io/ijin-tomodachi-puzzle/

- 同じ顔を3つ以上つなげてタップすると消えます。顔はお札の金額になっていて、お会計をぴったり払うとボーナス。
- このリポジトリには、公開用にビルドしたファイルだけを置いています。

## 素材・出典

- 偉人の肖像画像　出典：国立国会図書館『近代日本人の肖像』 https://www.ndl.go.jp/portrait/
  - 顔の部分を正方形に切り抜き、縮小し、丸い枠で表示する加工をしています。
  - 国立国会図書館が制作・公認したものではありません。
- 効果音は、ブラウザの中で合成した独自の音です。
- お札の画像・デザインは使っていません。ゲームの中の「お金」は本物のお金とは関係ありません。

## 写真について

自分や友達の写真を入れる機能は任意です。写真は端末のブラウザの中だけで加工し、サーバーや外部サービスには送りません。保存もしません（ページを閉じると消えます）。
